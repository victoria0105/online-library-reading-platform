# ReadShelf

## Online Library & Reading Platform

ReadShelf is an online library and reading platform designed to make it easy for users to discover, access, and read books online.

The goal of the project is to create a simple and user-friendly website where readers can search for books, view book information,
save books they are interested in, and read available books online.

## Project Goals

- Create an easy-to-use online library
- Help users quickly search and discover books
- Allow users to read available books online
- Allow users to save their favorite books
- Keep track of reading activity
- Provide book recommendations based on user interests and reading activity

## Planned Features

- User registration and login
- Book catalog
- Book search
- Book details page
- Online reading page
- Favorites / saved books
- Reading history
- User profile
- Book recommendations
- Simple and responsive website design

## Book Sources

The project will explore the use of public-domain books from sources such as Project Gutenberg.
